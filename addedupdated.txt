### `/.github/workflows/basketball_odds.yml`

### Workflow behavior

* **Manual only** — uses `workflow_dispatch`; no schedule or automatic trigger.
* Has **no manual inputs or required selections**.
* Runs:
  `docs/win/basketball/scripts/00_intake/basketball_odds.py`
* The Python script determines the leagues and date window automatically.
* Stages only:
  `docs/win/basketball/00_intake/sportsbook/sportsbook_cleaned/`
* Commits changes as `github-actions[bot]`.
* Pushes generated/updated odds CSVs back to the repository.
* If no cleaned odds files changed, it exits without creating an empty commit.

### `basketball_odds.py` summary

The Python script is the standardized odds intake process for **NBA, WNBA, and NCAAM**.

It:

1. Processes **all three leagues on every run**:

   * NBA
   * WNBA
   * NCAAM
2. Uses the time the script is run as the beginning of the collection window.
3. Pulls games scheduled from that moment through the **next 7 days**.
4. Uses ESPN's CDN scoreboard to discover games and obtain ESPN event/competition IDs.
5. Calls ESPN's Core odds endpoint for each eligible game.
6. Prefers **DraftKings** when ESPN supplies DraftKings odds; otherwise it uses the first available sportsbook provider.
7. Pulls ESPN's **current**:

   * spread
   * total
   * moneyline
   * American prices
   * decimal prices
8. Converts game dates/times to `America/New_York`.
9. Uses the script-run UTC timestamp for `odds_last_update` when new odds values are received.
10. Creates a row for a newly discovered game **even when odds have not been posted yet**. Odds fields remain blank until values become available.
11. If the game already exists, updates that existing row with newly pulled odds.
12. **Never replaces an existing nonblank value with a blank value.**
13. If ESPN has only some markets available, updates the available fields while preserving existing values in fields ESPN currently returns blank.
14. Skips completed games rather than updating them.
15. **Never deletes an existing game row.**
16. Preserves existing rows even when they are no longer returned in the current 7-day pull.
17. Maintains **one row per game**.
18. If duplicate rows with the same `game_id` already exist, consolidates them into one row, retaining the newest available odds while preserving older nonblank values where the newer row is blank.
19. Uses ESPN numeric game IDs for newly created rows, such as:
    `401857134`
20. Produces the established **23-column schema in the same order**.

### Output files

```text
docs/win/basketball/00_intake/sportsbook/sportsbook_cleaned/nba/YYYY_MM_DD_NBA_odds.csv

docs/win/basketball/00_intake/sportsbook/sportsbook_cleaned/wnba/YYYY_MM_DD_WNBA_odds.csv

docs/win/basketball/00_intake/sportsbook/sportsbook_cleaned/ncaam/YYYY_MM_DD_NCAAM_odds.csv
```

Each file is **updated in place** on subsequent runs rather than being rebuilt solely from the latest API response.

### Logging

Runtime and error information is written to:

`docs/win/basketball/errors/00_intake/basketball_odds.txt`

The workflow **does not commit this log**. It commits only changes under the cleaned sportsbook output directories.
