# Basketball model configuration
# Permanent league-level rules only.
# Dynamic rolling bias values should be calculated separately and are not stored here.
#
# Bias schema:
#   method: rolling      -> window_games required, value must be null
#   method: regime_aware -> windows_games + weights + sign_conflict_shrink required,
#                          value must be null
#   method: fixed        -> value required, window_games must be null
#
# regime_aware:
#   - calculates projected_minus_actual residual means for every configured window
#   - combines them with the configured weights
#   - if both positive and negative window means are present, multiplies the
#     weighted value by sign_conflict_shrink to avoid chasing an unstable regime
#
# Calibration schema:
#   moneyline may retain side-specific calibration.
#
#   spread / total use complementary binary calibration:
#     canonical_side: <side to calibrate>
#     <canonical_side>:
#       method: none | beta
#
#   The opposite spread/total side is NOT calibrated independently.
#   It is always derived as:
#       p_opposite = 1 - p_canonical
#
#   method: none -> no probability adjustment
#   method: beta -> p_adj = logistic(
#                       intercept
#                       + coef_log_p * ln(p_raw)
#                       + coef_log_1mp * ln(1 - p_raw)
#                   )
